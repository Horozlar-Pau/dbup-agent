# dbup-agent
DoNotBreakUp (dbup) — yazılımcının bilgisayarında çalışan, odak/AI/git aktivitesini takip eden ajan

İki parçadan oluşur: Go ile yazılan arka plan servisi (`dbupd`) ve Electron ile yazılan masaüstü arayüzü.
